# EcoColecta

Proyecto comunitario para registrar puntos de reciclaje y entregas de materiales reciclables.

## Evolución del control de versiones
El control de versiones ha evolucionado desde modelos centralizados, como SVN, donde todo el historial se guarda en un único servidor, hasta modelos distribuidos como Git, donde cada desarrollador tiene una copia completa del repositorio. Esto permite trabajar sin conexión, crear ramas fácilmente y mantener un historial más seguro y flexible.

## Diferencia entre Git y GitHub
Git es una herramienta local de control de versiones que permite gestionar cambios en el código. GitHub es una plataforma remota que aloja repositorios Git y facilita la colaboración, revisión de cambios, pull requests, issues, proyectos y automatización.
